# Jost

Default paragraph and interface font by Owen Earl / indestructible type*.

- Official specimen: https://fonts.google.com/specimen/Jost
- Upstream: https://github.com/indestructible-type/Jost
- Google Fonts source: https://github.com/google/fonts/tree/main/ofl/jost
- Downloaded 2026-10-20 from the official variable-font stylesheet:
  https://fonts.googleapis.com/css2?family=Jost:ital,wght@0,100..900;1,100..900&display=swap
- Upright Latin WOFF2 (v20): https://fonts.gstatic.com/s/jost/v20/92zatBhPNqw73oTd4g.woff2
- Italic Latin WOFF2 (v20): https://fonts.gstatic.com/s/jost/v20/92zUtBhPNqw73oHt4D4h.woff2
- License: SIL Open Font License 1.1; see `OFL.txt`.

The binaries are unmodified Latin subsets, each supporting weights 100–900.
The upright font is preloaded; italic is loaded when needed. All fonts are served
locally with `font-display: swap`, without external requests at runtime.
