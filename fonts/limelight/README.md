# Limelight Regular

Art Deco wordmark font by Nicole Fally / Sorkin Type Co.

- Official specimen: https://fonts.google.com/specimen/Limelight
- Upstream: https://github.com/google/fonts/tree/main/ofl/limelight
- Downloaded 2026-10-20 from Google's official webfont stylesheet:
  https://fonts.googleapis.com/css2?family=Limelight&display=swap
- Latin WOFF2 (v21): https://fonts.gstatic.com/s/limelight/v21/XLYkIZL7aopJVbZJHDuoOulH.woff2
- License: SIL Open Font License 1.1; see `OFL.txt`.

The font binary is unmodified. The Latin subset covers the CHITMON.COM
wordmark and the homepage's ¡BIENVENIDOS! heading. This is an alternative to the reference lettering,
not a claim that the stock artwork uses Limelight.
